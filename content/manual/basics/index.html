Basics

Before a game draws anything it is a folder, a config file, a command and a handful of headers. This group is about those four things: what each one is, which parts of it are yours, and why it is laid out the way it is.

  • Project layout — what rmp new puts in a game's folder, which parts you edit and which belong to the framework, and what the build generates.
  • Configuration — raylib_multiplatform.toml: the one file that drives CMake, Gradle and Xcode, and what happens when a value in it is wrong.
  • The rmp command — building, running, testing and shipping a game from one command, on every shell.
  • Headers — one header per module, no umbrella, and the RMP_ values every header carries from the config.

When the folder builds and runs, the core is next: the app, the scenes it moves between and the objects in them.
