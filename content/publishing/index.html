Publishing

A release is a git tag. rmp deploy checks the version the way CI will, tags it and pushes the tag; CI then builds every target your game has turned on and attaches them to a GitHub release.

rmp deploy 1.2.0

The version comes from the tag and from nowhere else: v1.2.0 becomes the version name on every platform, and the Android version code, so there is no number in the project to forget to bump.
