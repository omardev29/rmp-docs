Examples

The framework comes with {{count:examples}} examples. Each one is a small, complete project in its own folder under examples/, and {{count:games}} of them are whole games you can play from start to finish.

Every example is built by CI on every change to the framework, and every one that is a program — the plain C one included — is started, headless, with a screenshot taken of it, and has to boot with every asset loaded, draw and exit cleanly. An example that is a source file with no program in it is compiled, and has nothing to run. None of them can quietly stop working.

From a clone of the framework, rmp example lists them, and one runs with its name or its path:

rmp example
rmp example 01_pong
rmp example games/01_pong
