raylib_multiplatform

A C++20 framework for shipping raylib games to {{count:targets}} targets from one codebase — Windows, Linux, macOS, the web, Android, iOS and the three BSDs — with CI that builds every one of them and, on each one its runners can run, boots the game and checks that it put pixels on the screen.

You write the game. A main menu is three calls:

rmp::ui::begin();
if (rmp::ui::button("Play")) play();
if (rmp::ui::button("Quit")) quit();
rmp::ui::end();

That is a centred, responsive menu that a mouse, a keyboard, a gamepad and a finger can all use. No coordinates, no sizes, no fonts to load. Everything else the framework has is there when that default is not what you want, and costs nothing until then.

Underneath, it is raylib, and raylib stays yours: inside a scene you call DrawTexture, DrawCircle or BeginMode2D exactly as you would without the framework. What the framework adds lives under rmp::, one header per module, and a game includes only the ones it uses.
